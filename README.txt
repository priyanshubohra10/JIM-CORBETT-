HOW TO PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
4. Internet is needed for the sample photos and Google Fonts.

BEFORE PUBLISHING
1. Replace sample image URLs in styles.css with your own Gypsy, safari and business photos.
2. Verify all business details, operating areas, actual prices and services.
3. Do not advertise a permit, zone access, room, vehicle or safari as confirmed until it is verified with the relevant official authority.
4. Add a privacy policy if you later collect/store guest information.
5. Buy a domain only after checking availability and the total renewal price.

HOW TO PUBLISH FREE (GitHub Pages)
1. Create/sign in to a GitHub account.
2. Create a new public repository named corbett-wild-trails (or another available name).
3. Upload index.html, styles.css, script.js and README.txt to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish the site. The page will show the live URL.
8. Test the website on mobile and test the WhatsApp form.

CUSTOM DOMAIN
The domain corbettwildtrails.com is only a suggestion; availability has not been checked.
If you buy a domain, configure it in GitHub Pages settings and follow GitHub's displayed DNS instructions.
A domain purchase and DNS setup are separate from this starter website.

IMPORTANT
This is a static website starter, not a live booking/permit inventory system. The form opens WhatsApp and does not process payments or confirm bookings.


Current version focuses on Gypsy safari enquiries only. Visitors can either message directly through the WhatsApp button or submit the form to prepare a booking request message. The form does not take payment or confirm permits/availability. Replace sample images and verify all safari details before advertising.
